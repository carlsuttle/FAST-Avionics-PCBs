# FAST Avionics PCBs

KiCad 10 hardware designs for FAST avionics.

## Projects

- `FLIGHT CONTROLLER/` — FAST flight-controller schematic, PCB, fabrication outputs, component libraries, and design notes.
- `AS_GPS_XIAO_OUTBOARD/` — GPS/XIAO outboard schematic, PCB, fabrication outputs, and supporting libraries.

Open each `.kicad_pro` file with KiCad 10 or newer.

Local KiCad preferences, lock files, autosaves, backups, and history snapshots are intentionally excluded from version control.
